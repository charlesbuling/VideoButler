# 演示素材说明 / Demo media

本目录下的 GIF 都是 Video Butler 0.2.0 的真实操作录屏（Linux 上运行 `vb serve` 的网页界面，手动加载 ONNX Runtime），没有任何合成或生成的界面。

All GIFs in this folder are real screen recordings of Video Butler 0.2.0 (the `vb serve` web UI on Linux, with ONNX Runtime loaded manually). No UI was mocked up or generated.

| 文件 / File | 内容 / Shows |
|---|---|
| `draft.gif` | 新建项目 → 选素材文件夹 → 选风格 → 生成草稿 / new project → pick folder → pick style → generate draft |
| `butler.gif` | 视频管家：自动分类 + 回忆地图 / Butler: auto categories + memory map |
| `editor.gif` | 内置编辑器：播放、变速、撤销 / built-in editor: play, speed change, undo |
| `models.gif` | 模型页：按需下载模型 / Models page: download a model on demand |
